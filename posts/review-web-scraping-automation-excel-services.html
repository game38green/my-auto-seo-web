1. Web Scraping คืออะไร?

คือกระบวนการใช้บอท (Bot) เข้าไปอ่านหน้าเว็บไซต์และดึงข้อมูลที่ต้องการออกมาในรูปแบบที่นำไปใช้ต่อได้ เช่น CSV, Excel หรือ Database ซึ่งเหมาะมากสำหรับธุรกิจที่ต้องการ เปรียบเทียบราคาสินค้า หรือ ดึงข้อมูล Lead รายชื่อลูกค้า

2. พลังของ Python ในการจัดการ Excel

ลืมการเขียน Macro ใน Excel แบบเดิมๆ ไปได้เลย เพราะเราใช้ โปรแกรมเมอร์ Python สำหรับระบบ Automation และ Scraping ซึ่งสามารถจัดการข้อมูลขนาดใหญ่ (Big Data) ได้เร็วกว่าหลายเท่าตัว การใช้ไลบรารีอย่าง Pandas ทำให้การ Clean ข้อมูล และ Merge ไฟล์ กลายเป็นเรื่องง่ายเพียงแค่กดปุ่มเดียว
